## 📢 CO-FOUNDER WANTED: Software & Integration Specialist

This is not a junior role or a freelance contract. The hardware architecture, industrial design, and field operational framework are locked. What remains is the digital layer — and that layer needs an owner, not a contractor.

### What You Will Own:
* **Edge-to-Cloud Data Pipeline:** Building a reliable data path from a field device to a server to a UI using MQTT, WebSocket, or raw TCP.
* **IoT Backend Architecture:** Designing database schemas for time-series sensor data, device shadows, and message brokers.
* **Dashboard & Web Interface:** Shipping a real-time, fast, responsive monitoring dashboard.
* **Embedded Integration:** Understanding what the firmware exposes (SPI, I2C, UART, BLE) to build reliably on top of it without breaking hardware assumptions.

### The Stack:
`ESP32-S3` · `nRF9160 LTE` · `MQTT / WebSocket` · `Time-Series DB` · `REST / Edge API` · `React or equivalent` · `Docker` · `Linux`
